# AEC Stage 7.2 Host Command Protocol

This file defines the text protocol consumed by `rtl/tb_system.sv` and
generated by `runtime/aec_runtime_sim.py`.

Commands are ASCII, one command per line. Hex fields may be written without a
`0x` prefix.

WRITE_AXI <hex_addr> <hex_data>
  Write one 32-bit little-endian word into the testbench AXI main-memory model.

WRITE_AXIL <hex_addr> <hex_data>
  Write one 32-bit word through the AXI4-Lite CSR/IMEM window.

POLL_AXIL <hex_addr> <hex_mask> <hex_expected>
  Repeatedly read AXI4-Lite until `(read_value & mask) == expected`.

DUMP_AXI <hex_addr> <num_words> <filename>
  Dump `num_words` 32-bit little-endian words from AXI main memory into a hex
  text file, one 8-digit word per line.
